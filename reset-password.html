After the new file is published, use **Forgot Password?** from your admin page to generate a **new reset email**. Don't use the old reset link. Then the expected sequence is: **Email reset link → Reset Password page → “You can now create your new password” → enter password → Update Password → “Password updated successfully!” → Admin Login.**
